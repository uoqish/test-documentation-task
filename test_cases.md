Тест-кейсы для интернет-магазина книг

Предусловия:
1. Пользователь не авторизован
2. В каталоге есть книга "Мастер и Маргарита" (цена 500 руб.)
3. У пользователя есть тестовая карта для оплаты

Шаги выполнения:

| № | Действие | Входные данные | Ожидаемый результат |
|---|----------|----------------|---------------------|
| 1 | Открыть главную страницу магазина | URL: https://bookstore.ru | Главная страница загрузилась, виден поиск и категории |
| 2 | Ввести название в поиск | "Мастер и Маргарита" | Появился список результатов, в котором есть нужная книга |
| 3 | Нажать на книгу | - | Открылась карточка товара с описанием, ценой и кнопкой "В корзину" |
| 4 | Нажать "В корзину" | - | Кнопка изменилась на "В корзине", появилось уведомление |
| 5 | Перейти в корзину | Нажать иконку корзины | В корзине видна книга "Мастер и Маргарита", цена 500 руб., итого 500 руб. |
| 6 | Нажать "Оформить заказ" | - | Открылась форма оформления |
| 7 | Заполнить данные получателя | Имя: Петр<br>Телефон: 999-123-45-67<br>Адрес: ул. Ленина, д.1 | Поля заполнились, кнопка "Перейти к оплате" активна |
| 8 | Нажать "Перейти к оплате" | - | Открылась форма оплаты |
| 9 | Ввести данные карты | Номер: 4111 1111 1111 1111<br>Срок: 12/25<br>CVV: 123 | Поля заполнены |
| 10 | Нажать "Оплатить" | - | Появилось сообщение "Оплата прошла успешно!" |

Ожидаемый результат всего теста:
- Пользователь видит сообщение об успешной оплате
- На email приходит письмо с подтверждением заказа
- В личном кабинете появляется этот заказ
- Количество книг на складе уменьшилось на 1

Постусловия:
- Очистить тестовые данные (отменить заказ в тестовой среде)
- Вернуть количество книг на складе

Тест-кейс 2: Ошибка при оформлении заказа без адреса

Предусловия:
1. Пользователь авторизован (логин: test@mail.ru, пароль: 12345)
2. В корзине есть книга "Преступление и наказание"

Шаги выполнения:

| № | Действие | Входные данные | Ожидаемый результат |
|---|----------|----------------|---------------------|
| 1 | Перейти в корзину | Нажать иконку корзины | Открылась корзина с товаром |
| 2 | Нажать "Оформить заказ" | - | Открылась форма с полями: Имя, Телефон, Адрес, Email |
| 3 | Заполнить поля (кроме адреса) | Имя: Иван<br>Телефон: 999-888-77-66<br>Email: ivan@mail.ru | Поля заполнены, поле "Адрес" пустое |
| 4 | Нажать "Перейти к оплате" | - | Кнопка не нажимается ИЛИ появляется ошибка |
| 5 | Проверить сообщение об ошибке | - | Под полем "Адрес" появился красный текст: "Поле обязательно для заполнения" |
| 6 | Заполнить адрес | ул. Тверская, д.10, кв.5 | Красное сообщение исчезло |
| 7 | Снова нажать "Перейти к оплате" | - | Переход к оплате произошел успешно |

Ожидаемый результат всего теста:
- Система не позволяет перейти к оплате без обязательных полей
- Пользователь видит понятную подсказку, что именно нужно исправить
- После исправления ошибки можно продолжить оформление

Постусловия:
- Отменить заказ (если он создался)
- Очистить тестовые данные

Тест-кейс 3: Отмена заказа в процессе оформления

Предусловия:
1. Пользователь авторизован
2. В корзине есть книга "Анна Каренина"
3. Пользователь на шаге заполнения данных доставки

Шаги выполнения:
1. На странице оформления заказа найти ссылку "Продолжить покупки"
2. Нажать на эту ссылку
3. Перейти в каталог и добавить еще одну книгу
4. Вернуться в корзину

Ожидаемый результат:
- После нажатия "Продолжить покупки" пользователь возвращается в каталог
- Корзина сохраняет все ранее добавленные товары
- При возврате в корзину книга "Анна Каренина" все еще там
- Добавленная новая книга тоже отображается в корзине

Постусловия:
- Очистить корзину
